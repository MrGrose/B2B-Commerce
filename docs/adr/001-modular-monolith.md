# ADR-001: Modular monolith

Status: Accepted

## Context

Нужен backend для B2B-магазина с несколькими доменами (каталог, склад, счета). Микросервисы усложняют транзакцию «счёт + резерв».

## Decision

Один FastAPI-процесс. Домены — пакеты с явными границами.

## Consequences

Резерв и счёт живут в одной БД-транзакции. Масштабируем процессом, не сетью. Резать на сервисы не из эстетики.
