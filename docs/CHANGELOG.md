# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/).
Версии: [Semantic Versioning](https://semver.org/).

## Как вести

1. Пока работаешь — пиши пункты в **`[Unreleased]`** (Added / Changed / Fixed / Removed).
2. Перед релизом: переименуй `[Unreleased]` в `[X.Y.Z] — YYYY-MM-DD`, добавь новый пустой `[Unreleased]`.
3. Один пункт = одно изменение для читателя; без внутренних ID задач.
4. Не смешивай breaking change с мелким фиксом в одной строке — отметь в **Changed** или **Removed**.

## [0.1.0] — 2026-03-20

### Added

- Корзина с проверкой остатков при добавлении и оформлении.
- Черновик счёта из корзины и жизненный цикл статусов.
- Импорт прайса из XLSX (лист `Прайс`) с картинками товаров.

### Changed

- Каталог показывает только активные товары с остатком > 0.

### Fixed

- Повторное оформление не создаёт дубликаты позиций счёта.

## [0.0.1] — 2026-03-01

### Added

- Вход по email/паролю, роли admin и customer.
- Базовый каталог и карточка товара.
- Docker Compose для локального запуска (app, Postgres, MinIO).
